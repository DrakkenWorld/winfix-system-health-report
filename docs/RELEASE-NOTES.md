# WinFix System Health Report 1.0.0

Téléchargez le ZIP, extrayez tous les fichiers, puis double-cliquez sur **Start-FR.cmd**. Le rapport HTML s’ouvre dans votre navigateur. Le dossier **WinFix-Reports** contient aussi le fichier JSON.

Download and extract the ZIP, then double-click **Start-EN.cmd**. The HTML report opens in your browser. The **WinFix-Reports** folder also contains the JSON report.

- Windows, hardware, fixed drives, drivers and recent event counts.
- Local read-only collection with clear status for unavailable sources.
- Windows PowerShell 5.1 included with Windows 10/11. PowerShell 7 also supported from the command line.
- MIT license, French and English guides, SHA-256 checksum.
