# WinFix System Health Report 1.1.0

**Application Windows portable** — téléchargez **WinFix-SystemHealthReport-Windows-x64.exe**, double-cliquez dessus et choisissez **Créer le rapport**. L’interface est disponible en français et en anglais. Les rapports sont enregistrés dans Documents → WinFix-Reports par défaut. Les boutons permettent d’ouvrir le rapport ou son dossier.

**Portable Windows application** — download **WinFix-SystemHealthReport-Windows-x64.exe**, double-click it, then choose **Create report**. Use the result buttons to open the HTML report or its folder. The app uses components supplied with Windows 10/11 x64. It is unsigned.

## Archive PowerShell / PowerShell ZIP

Téléchargez le ZIP, extrayez tous les fichiers, puis double-cliquez sur **Start-FR.cmd**. Le rapport HTML s’ouvre dans votre navigateur. Le dossier **WinFix-Reports** contient aussi le fichier JSON.

Download and extract the ZIP, then double-click **Start-EN.cmd**. The HTML report opens in your browser. The **WinFix-Reports** folder also contains the JSON report.

- Windows, hardware, fixed drives, drivers and recent event counts.
- Local read-only collection with clear status for unavailable sources.
- Windows PowerShell 5.1 included with Windows 10/11. PowerShell 7 also supported from the command line.
- MIT license, French and English guides, SHA-256 checksum.
